# Paper template

Copy this directory into a new numbered, kebab-case paper directory. Replace
the bracketed prompts and remove guidance text before publication. Put diagrams
in `diagrams/`, reproducibility materials in `artifact/`, and architectural
decisions in `adr/`.

Use `paper.md` as the document outline. For a registered report, complete the
research questions, methods, analysis plan, and decision criteria before
collecting or examining outcome data.
