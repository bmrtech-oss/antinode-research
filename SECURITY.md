# Security Policy

## Scope

This repository contains research and design documents, templates, and
diagrams. It is not a supported production service and does not accept or
process confidential data.

## Reporting a concern

Please do not publish credentials, personal data, or exploit details in an
issue or pull request. Report suspected security issues privately to the
repository maintainers through GitHub's security advisory reporting feature.
Include the affected path, impact, and a reproducible description where safe.

Maintainers will acknowledge reports as soon as practical and coordinate any
necessary correction or disclosure with the reporter.
