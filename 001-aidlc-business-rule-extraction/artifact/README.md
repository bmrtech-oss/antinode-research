# Research artifact

This directory is reserved for materials needed to inspect or reproduce the
proposed evaluation. Version-controlled artifacts should be non-sensitive and
include their provenance, license, and instructions.

Before running an evaluation, add:

- a data manifest with source identifiers, versions, inclusion decisions, and
  permitted-use notes (do not commit confidential source documents);
- the exact schema, taxonomy, and configuration versions used;
- a run protocol with commands, environment, and expected outputs;
- reference-set annotation guidance and adjudication records; and
- analysis code and machine-readable results, with personally identifying or
  confidential details removed as required.

The registered report is a plan, not evidence that these artifacts or
evaluation results already exist.
